SQuIRL IR Analysis

About the project

This project explores the relationship between molecular structure, physicochemical properties, and calculated vibrational infrared (IR) spectra using the SQuIRL (Spectral Quantum Chemistry and Infrared Resonance Library) dataset.

The main question is:

How are molecular structure and molecular properties reflected in vibrational and infrared spectral behavior?

Objectives

* Explore the calculated vibrational spectra of organic molecules.
* Examine relationships between molecular properties and IR intensity.
* Investigate spectral regions associated with different structural features.
* Compare IR behavior of molecules containing selected functional groups.

Dataset

The project uses the publicly available SQuIRL dataset, which contains calculated molecular structures, physicochemical/electronic properties, and harmonic vibrational IR data.

The original SQuIRL dataset is not included in this repository because of its large file size.

Computational tools

* Python
* Pandas
* NumPy
* Matplotlib
* RDKit
* h5py
* Google Colab

Analysis

The computational workflow includes:

1. Dataset inspection and cleaning
2. Data validation
3. Vibrational-mode validation
4. Molecular descriptor analysis
5. IR spectral analysis
6. Spectral-region analysis
7. Functional-group comparisons
8. Correlation analysis
9. Visualization and interpretation

Repository contents

The repository contains the computational notebook and, as the project develops, selected figures and summary results.

Status

This project is currently under development. The computational analysis is being finalized before preparation of the scientific report.
